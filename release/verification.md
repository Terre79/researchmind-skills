# Windows x64 CPU 预览包验收

每个 ZIP 在本地 Windows x64 机器上单独解压到含中文和空格的临时路径。验证脚本清除系统 Python 路径、Python 环境变量和模型配置，只使用包内的 `python/python.exe` 与内置资产。离线验证禁用对外 HTTP(S) 代理路径，推理模型直接在本机执行。在线检索验证使用公开服务。

| Skill | 实际输出 |
| --- | --- |
| 晶体生成 | CPU 使用原版 CrystaLLM 权重采样，生成两份 SHA-256 不同的 NaCl CIF，均经脚本重新解析。 |
| 材料查询 | 用 OQMD 实时查到两条硅记录，导出两份对应 CIF。 |
| 结构优化 | MatterSim 对硅计算能量约 −10.825 eV。扰动结构弛豫后最大原子受力从约 1.398 降至 0.013 eV/Å，重新解析输出 CIF。 |
| 声子分析 | 对硅使用 MatterSim 和 Phonopy，导出 PNG 及 1296 个有限的 THz 频率值。 |
| 文献检索 | 从真实 PDF 导入记录并导出 CSV，使用内置 Qwen 生成检索计划；在线从 arXiv 查回指定论文。 |
| 论文分析 | 从真实论文提取 19,201 字符，使用内置 Qwen 生成分析。 |
| 研究报告 | 使用内置 Qwen 生成单篇报告，核对 arXiv 引用 ID `cond-mat/0211520v2`。 |
| 文献知识库 | 使用内置 Qwen3 嵌入两篇论文的 168 个片段，重启后用中文和英文查询均命中目标论文。 |

热导率已用上游原版权重在源码环境实算 Kappa-P 和 Kappa-MTP，获得有限正值及 CSV。公开分发权重需权利人许可，暂不发布该 ZIP。

还需补做无 Visual C++ v14 系统库的干净 Windows 安装和目标 Agent 的安装回归。具有本地执行权限的宿主可直接调用包内 Python。在线数据库仍需要网络；账户型服务需要凭据。历史源码检索测试中的 Tavily、Materials Project 和限流来源未纳入本次成功项。
